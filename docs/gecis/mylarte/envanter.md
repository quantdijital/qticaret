### 2.3 Yönlendirmeler (tarayıcı fetch'i ile; durum kodu 301/302 ayrımı görülemedi)
- Eğik çizgisiz URL → eğik çizgili (`/el-yapimi-caki` → `/el-yapimi-caki/`, `/urun/x` → `/urun/x/`, `/hesabim` → `/hesabim/`).
- `/urun-kategori/x/`, `/kategori/x/`, `/product-category/x/`, `/etiket/x/` → `/x/`.
- Alt kategori kökte çağrılırsa tam yola gider: `/n690-cakilar/` → `/el-yapimi-caki/n690-cakilar/`.
- Boş sepette `/odeme/` → `/sepet/`.
- Tüm ürünleri tek sayfada gösteren kategorilerde `/page/2/` → kategori köküne.
- Filtre formu `/magaza/?mlcf_category=el-yapimi-caki&orderby=date&filter_celik=n690&min_price=&max_price=` → `/el-yapimi-caki/?filter_celik=n690&orderby=date` (boş parametreler atılıyor).
- 404 dönenler: `/shop/`, `/cart/`, `/checkout/`, `/my-account/`, `/author/admin/`, ürün slug'ı kökte (`/{urun-slug}/`).
- Site içi linkler yönlendirme üzerinden geçiyor: ana sayfa bölüm başlıkları `/kategori/el-yapimi-caki`, `/kategori/mutfak-sef-serisi`, `/kategori/ozel-koleksiyon`, "Yeni Ürünler" → `/magaza` (eğik çizgisiz).

### 2.4 Canonical, robots, sayfalama, filtre
- Canonical her sayfada kendine (sayfalama sayfaları dahil: `/magaza/page/2/` canonical kendisi, index). `rel=next` var.
- `?orderby=` → canonical temiz URL'ye, index. `?filter_celik=`, `?filter_urun-turu=`, `?min_price=`/`?max_price=` → `noindex`, canonical yok.
- Ürün URL'sine `?attribute_pa_…` eklenince canonical temiz.
- Arama, etiketler, sepet/ödeme/hesap, 404: `noindex`. Toptan sayfaları: `noindex, nofollow`.
- Sıralama değerleri: `menu_order` (Önerilen), `popularity` (En çok satanlar), `rating` (Değerlendirme puanı), `date` (En yeni — varsayılan görünüyor), `price`, `price-desc`.
- Sayfa başı 12 ürün; **bazı kategoriler tüm ürünleri tek sayfada** gösteriyor (el-yapimi-caki 54, outdoor-kamp 50, kasap-bicaklari 26, av-bicagi 24, el-yapimi-bicak 12, sef-bicaklari 16…), bazıları 12'li sayfalıyor (ozel-koleksiyon 30, kilic-modelleri 14, n690-cakilar 32, magaza 197). Kategori bazlı ayar gibi.
- Sayfalama tipi: numaralı (1 2 3 … 17 →). Sonsuz kaydırma / "daha fazla" yok.
- `hreflang` yok, tek dil `tr`.
